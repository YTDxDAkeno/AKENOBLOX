# Releases

`tools/build/build-ps5.sh` writes `AkenoBlox-PS5-<version>-<commit>.zip` here
(ignored by git). Each ZIP holds the title folder `PPSA99256/`, the
installation and hardware-testing guides, the licence and notices, and
`BUILD.txt` naming every pinned input and the `eboot.bin` digest.

A release is published only with a title that says what it is: until a console
run is recorded, builds are test builds for hardware testing, not a way to play
Roblox (docs/ROADMAP.md, "Release plan").
